# TokCom 论文复现：第十八阶段跨指标一致性诊断（2026-11-02）

本阶段把第十一阶段的 100 张开发验证图 PSNR 结果与第十七阶段的冻结 ResNet18 特征结果逐图配对。两组结果的图像 SHA-256、数据身份、MaskGIT 权重、信道种子 `20261021`、PER 30% 与每图擦除 token 数均一致。所有差值均定义为**预训练 MaskGIT 一步恢复减空间填补**。

## 逐图对照

| 两种图像指标的排序 | 图像数 |
|---|---:|
| PSNR 与 ResNet18 特征相似度都支持预训练恢复 | 92 |
| PSNR 支持预训练恢复，特征相似度支持空间填补 | 5 |
| PSNR 支持空间填补，特征相似度支持预训练恢复 | 3 |
| 两种指标都支持空间填补 | 0 |

因此 **8/100 张图**的 PSNR 和特征余弦相似度对两种方法给出相反排序。这 8 张图中，两种方法与原图的 ResNet18 top-1 预测一致状态均相同，不能靠这一二值指标裁定哪种重建更好。逐图 PSNR 差与特征差的 Pearson 相关为 **0.192**，只作这批图的描述性统计。预训练方法在 **100/100 张图**的缺失 token 精确命中率都高于空间填补；但这并未使图像层面每一张图、每一个指标都得到相同排序。token 命中优势与 PSNR 差的逐图相关为 **0.539**，与特征差为 **0.185**，同样不作因果解释。

## 解释边界

PSNR 衡量像素误差，ResNet18 余弦相似度衡量一个冻结分类模型的图像表示；二者的单位和含义不同。较低的逐图相关提醒我们不能用一个指标直接替代另一个指标。ResNet18 在 ImageNet 上预训练，而 Imagenette 来自 ImageNet，存在预训练数据重叠风险。全部图像均属开发验证集，且本轮是读取已有结果做事后分析，不构成新盲测或论文 CLIP/LPIPS 评测。

复现的下一项关键工作仍是完整控制协议与等资源比较，以及更贴近论文目标的感知或语义评测。方法冻结后须另设新的项目独立留出集；已查看的第十阶段留出集不能再用于新方法盲测。
