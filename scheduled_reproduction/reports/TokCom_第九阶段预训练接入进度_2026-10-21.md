# TokCom 论文复现：第九阶段预训练接入进度（2026-10-21）

本轮将接收端的下一步从“继续训练小模型”转向“核验公开预训练 MaskGIT 能否与现有图像 tokenizer 对接”。这是开发验证，不是新的独立测试，也不是完整 TokCom 模型。

## 权重与 token 兼容性

采用 [Google 官方 MaskGIT](https://github.com/google-research/maskgit) 所列 ImageNet-256 权重的[第三方 PyTorch 转换](https://github.com/hmorimitsu/maskgit-torch)，源码固定在提交 `40c45116cfe48b2c9fec1e038e635bfc45ed59f8`。转换仓库注明仅支持推理，权重是官方 JAX 权重的直接转换。本项目现用 VQGAN 文件来自 TiTok 的[官方 JAX 权重转换说明](https://huggingface.co/spaces/yucornetto/RAR/blame/29dcf963df85ee88c544e9acfc98896a6cdae0f2/README_TiTok.md#L629-L632)。

- 现用 VQGAN SHA-256：`424e7f2b11d1d63691ae3fbab74cf6c417ecbe0d8f86187b71f3538c7b56f6d2`。
- 第三方转换 tokenizer SHA-256：`56ffdfd633284747b9afffbc2050ac07ff0903df828c4a694823c2fa274efd09`。
- 两者 1,024×256 码本权重逐值完全相同。公开样例及 stage5 验证集每类首张，共 11 张图像、2,816 个 token ID，逐个完全相同。这为沿用现有 token 缓存接入预训练 Transformer 提供了直接证据。
- 统一将输出裁剪到 `[0,1]` 后，两个解码器在这些样例上的平均绝对像素差约 `4.87×10⁻⁷`，最大绝对差约 `4.94×10⁻⁵`。未裁剪时的较大边界差来自输出范围处理；仍不声称逐位浮点等价。

## 类别条件问题

预训练 ImageNet-256 Transformer 需要在 256 个图像 token 前附加一个类别 token，图像 token 词表为 `0..1023`、类别 token 为 `1024..2023`、掩码 token 为 `2024`。把真实类别直接喂给接收端会引入未传输的“上帝视角”信息，只能作为上界诊断。把类别位置也掩码则不提供类别侧信息，但属于该预训练模型的训练分布外输入。两者都不能直接当作公平的无侧信息接收结果。

本轮还实现了接收端推断类别的路径：仅从已接收 token 出发，先用空间填补和 VQGAN 解码，再由冻结的 ImageNet ResNet18 推断类别。固定丢包率 30%、种子 `20261021`、验证集每类首张共 10 张时，推断类别正确 8/10；它不使用真实类别，但增加了一个预训练分类器与相应算力，比较时必须单列。

## 接收端预评估

转换 Transformer 权重已完整下载（`689,918,319` 字节），SHA-256 为 `101f9427378872582c68d92698824aa814c60d68342fdd645cb7dc03ecd3b46f`，模型参数全部匹配并通过单图推理。固定种子 `20261021`、PER 0.3 下，验证集首张 tench 图有 76 个丢失 token：真实类别条件命中 21/76，类别掩码命中 22/76，第七阶段模型一步命中 3/76，空间填补命中 0/76。**这只是加载与流程烟雾测试，不是性能结论**：样本仅一张，且未覆盖接收端推断类别路径。下轮将按已编写的固定协议在验证集每类首张上运行五种对照，再视结果决定是否扩展到完整验证集。第七阶段独立留出集本轮没有被访问。

## 方法与限制

stage5 token 缓存采用 `PIL ImageOps.fit` 的 Lanczos 预处理，而转换仓库的图像重建示例采用 bicubic；这不会改变“同一已缓存 token ID 是否可作为 Transformer 输入”的码本一致性结论，但可能影响生成模型在该数据分布上的表现。本轮只报告被抹除 token 的精确恢复，且任何 10 张验证图结果都只是探索性线索，不能宣布泛化提升。若预训练方案有效，下一步应在完整验证集冻结方案，再建立**新的**独立留出集评估；已经用于第七阶段测试的留出集不能重新当作盲测。

增量包只提供本轮自编的兼容性核查、接收端类别推断和评估脚本及结果 JSON，不重新分发约 218 MB 的第三方 tokenizer、约 690 MB 的 Transformer 或第三方源码。权重下载地址见上述转换仓库；运行依赖其固定提交版本，以及 `ml-collections==0.1.1`、`einops==0.8.1`。源码和权重保留在本机工作目录，交付包记录权重 SHA-256 以便核验。
