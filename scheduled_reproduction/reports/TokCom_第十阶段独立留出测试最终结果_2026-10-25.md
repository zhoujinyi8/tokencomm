# TokCom 论文复现：第十阶段独立留出测试最终结果（2026-10-25）

本阶段按测试前冻结的协议，完成了新留出集上 **15/15 个预设案例**。这验证的是 TokCom 轻量接收端的擦除 token 恢复，不等同于原论文完整系统复现。

## 测试设置

- 新留出集：Imagenette 验证源中每类 10 张，共 100 张；与此前 pilot、stage5、stage7 划分在文件哈希和解码像素哈希上均无交集。
- 发送端：冻结的 ImageNet-256 VQGAN tokenizer，256 个离散 token；每包 4 个 token。接收端只补被擦除的位置。
- 主方法：冻结的公开预训练 MaskGIT Transformer，类别前缀设为掩码 token `2024`，一步 argmax；未向接收端提供真实类别。它是类别条件模型的超出训练分布用法。
- 对照：第七阶段小模型一步 argmax、空间填补；每个案例共用相同的包擦除掩码。
- 丢包率 PER 为 10%、30%、50%；每档五个预先指定的信道种子 `20261101..20261105`。主指标为被擦除位置的**精确 token 命中率**。
- 在测试 token 编码与评估前已冻结协议、权重哈希、留出清单哈希、种子和指标；本轮仅续跑其余案例，没有按留出结果调整方法。

## 完整独立留出结果

每档五个种子使用同一批 100 张图，表中的 token 总数是跨种子累加，**不能当作独立图像样本数**。

| PER | 被擦除 token | 预训练类别掩码 | 第七阶段小模型 | 空间填补 | 相对空间填补提升 |
|---:|---:|---:|---:|---:|---:|
| 10% | 12,792 | 2,911 / 12,792 = **22.76%** | 174 / 12,792 = 1.36% | 275 / 12,792 = 2.15% | **+20.61 个百分点** |
| 30% | 38,780 | 7,412 / 38,780 = **19.11%** | 455 / 38,780 = 1.17% | 788 / 38,780 = 2.03% | **+17.08 个百分点** |
| 50% | 63,864 | 9,594 / 63,864 = **15.02%** | 722 / 63,864 = 1.13% | 1,314 / 63,864 = 2.06% | **+12.97 个百分点** |

这三个差值是预设测试范围内的描述性结果。没有把跨种子的重复 token 当成独立样本来计算显著性。与开发验证集约 22.97%、20.03%、15.52% 的主方法结果相比，新留出集结果量级接近；30% 档略低。公开预训练权重可能接触过 ImageNet 生态中的同源图像，因此这里的“独立留出”仅指本项目此前划分与调参流程，**不能证明与预训练数据完全隔离**。

## 可复查材料与下一步

交付包包含冻结协议 `protocol.json`、15 个案例的逐图和逐种子计数、最终汇总 JSON、评估及汇总脚本、留出集清单和图像。第三方预训练权重约 690 MB，没有重新分发。原始留出清单 SHA-256 为 `a323582848608f519dc131013efa1c583837a6e582681c5a9243f1541bb0526c`；预训练 Transformer 检查点 SHA-256 为 `101f9427378872582c68d92698824aa814c60d68342fdd645cb7dc03ecd3b46f`。

本结果说明公开预训练先验在当前擦除 token 精确恢复任务上明显强于两个现有基线。尚未复现原论文的自适应策略、反馈与重传链路，以及完整语义感知指标。下一阶段应在开发集上实现这些链路或语义指标，并为新增方法另设独立评估，避免用本留出集结果继续调参。
