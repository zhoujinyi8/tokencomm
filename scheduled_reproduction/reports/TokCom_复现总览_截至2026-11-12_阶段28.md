# TokCom 复现总览（截至 2026-11-12，阶段 28）

目前完成的是**公开预训练 VQGAN/MaskGIT 与本项目参考数字链路上的分阶段复现和诊断**，并非论文完整系统。最新成果集中在接收端恢复、图像重建、重传选包、反馈控制包及图像特征诊断。

| 阶段 | 数据与设置 | 已完成的主要结果 | 结论边界 |
|---|---|---|---|
| 第十阶段 | 新的 100 图独立留出集，PER 10%/30%/50%，每档 5 信道种子 | 预训练接收端精确 token 恢复率 **22.76% / 19.11% / 15.02%**；均高于空间填补与小模型基线 | 留出集与本项目旧划分独立；不能证明与公开 ImageNet 预训练数据完全隔离 |
| 第十一阶段 | 100 图开发验证集，PER 30% | 解码图像平均 PSNR：预训练 **16.70 dB**、空间填补 **15.15 dB**；97/100 图更高 | PSNR 是像素指标，不代表语义或主观质量；未做新盲测 |
| 第十二阶段 | 开发集，理想完美补发，PER 30%，5 信道种子，每图 4 包 | 低置信度选包比随机选包精确期望高 **1.51 个百分点** | 只模拟直接修复，不含物理补发、反馈或开销 |
| 第十三阶段 | 开发集，Rayleigh 8 dB，3 信道种子，数据包实际重传 | 低置信度 **30.73%**，单次随机选包 **29.99%** | 反馈包编号假设可靠送达；随机对照次数有限 |
| 第十四阶段 | 同上，每个图像与信道种子做 5 次随机选包 | 低置信度 **30.73%**，随机均值 **30.01%** | 三种子复用同一 100 张图；仍是开发集 |
| 第十五阶段 | 在第十四阶段结果前增加 24 bit 控制反馈包，经 CRC、卷积码、16-QAM、Rayleigh 信道 | 首个反馈种子下低置信度 **28.16%**、随机均值 **27.32%**；六个反馈种子的策略差值范围 **+0.13 至 +0.85 个百分点** | 单次反馈，无完整包头、ACK、导频或论文原始 TCE 策略 |
| 第十六阶段 | 反馈 CRC 失败后最多重发一次，按实际解出的包编号触发补发 | 首个反馈种子下低置信度 **29.88%**、随机均值 **29.30%**；六个反馈种子的策略差值范围 **+0.58 至 +0.89 个百分点** | 超时没有建模时长；仍无包头、ACK、导频，且未做等资源或新盲测 |
| 第十七阶段 | 同一 100 图开发验证集，冻结 ResNet18 图像特征代理指标 | 预训练恢复与原图平均余弦相似度 **0.9309**，空间填补 **0.8827** | 不是论文 CLIP/LPIPS；ImageNet 预训练重叠风险，且未做新盲测 |
| 第十八阶段 | 将第十一与十七阶段的同一 100 图结果逐图配对 | 92 图 PSNR 与 ResNet18 特征都支持预训练恢复；**8 图排序相反** | 事后开发集诊断；不能由单一指标推断完整语义质量 |
| 第十九阶段 | 在反馈包编号前加入 16 bit 类型与序号包头，仍最多反馈两次 | 主反馈种子下低置信度恢复 **29.57%**、随机均值 **28.84%**；反馈每次从 23 增至 31 个符号 | 参考包头设计；无 ACK、导频、完整时延或新盲测 |
| 第二十阶段 | 固定官方公开仓库提交并审计演示代码 | 确认官方演示的 AWGN、CRC11、固定交织、真实类别与 32 步生成等设置；列出与当前参考链路差异 | 官方仓库提交只提供演示，未见完整 TCE/反馈重传实现；已核对作者源码，权重兼容性另见第二十一阶段 |
| 第二十一阶段 | 作者 VQGAN 权重与现用社区权重，10 张开发图 | 作者权重哈希及模型参数已核验；2,560 个 token 仅 2 个编号相同 | 旧 token 缓存不可直接用于作者模型，旧指标仍只属于社区版路径 |
| 第二十二阶段 | 作者原始 GenDecoding，单张开发图，64/256 掩码，3 个采样种子 | 设定最多 32 步，均在第 14 步填完；原 token 命中 6/64、8/64、8/64 | 仅功能检查，未接 AWGN/CRC11，不能作为论文平均性能 |
| 第二十三阶段 | 作者多步解码，10 类开发图各 1 张，中心裁剪 | 67/640 token 命中，均第 14 步填完 | 无物理信道；仅开发集；中心裁剪非作者演示预处理 |
| 第二十四阶段 | 同图同种子，改用作者演示的整图缩放 | 63/640 命中；4 图更高、6 图更低 | 两种预处理生成不同 token，不能视为论文性能比较 |
| 第二十五阶段 | 独立 Sionna 0.19.2 链路，合成 token | 40/51/102 bit 每包、1,632 QAM 符号；8 dB 的 20 组样本中数据错误包 100，CRC 失败包 202 | 合成 token，无图像重建；演示真值比较与 CRC 遮蔽不同 |
| 第二十六阶段 | 作者 VQGAN 的十类开发图 token，AWGN 8 dB，每图五次 | 50 次共 3,200 包，数据错误 215 包、CRC 失败 452 包 | 开发集物理链路；该阶段仅完成物理层，生成与 MSE 见阶段 27–28 |
| 第二十七阶段 | 第 26 阶段的同一物理接收，先检查 2 张开发图 | 作者 GenDecoding 可以对真值比较及 CRC 遮蔽分别生成结果 | 单轮、单种子，仅单图功能检查 |
| 第二十八阶段 | 第 26 阶段第 0 轮物理接收，10 张开发图，同一采样种子 | 真值比较遮蔽 2,389/2,560 token 正确，CRC 遮蔽 2,220/2,560；对干净 VQGAN 图的平均 MSE 0.00305/0.00750 | 两分支已知信息不同；仅开发图、单物理轮次；非论文指标 |

第十阶段是目前最近一次**先冻结协议再测试新的项目留出集**的实验；后续第十一至二十八阶段属于开发验证和工程诊断。第十阶段留出图已被查看，不能继续拿来为新方法作盲测。三个数据链路种子与多个反馈种子会复用同一批图像，因此统计时以图像为单位聚合，不能把重复结果当成几百张独立图。

下一步优先事项：

1. 对已保存的其余四轮作者物理接收重复十图配对重建，按图像聚合；之后明确控制与 ACK 状态机，计入数据包头、ACK、导频和重试时延，并报告相同发送资源约束下的性能。
2. 继续补齐论文 CLIP/LPIPS 或等价语义与感知评测；保留 ResNet18 代理指标、PSNR 与 token 命中率的不同边界。
3. 对完成的链路冻结协议并准备新的留出数据，再评估一次，避免开发集结果被误称为最终论文复现指标。

详细方法、逐图结果与脚本分别见同目录的第十至二十八阶段报告及对应 ZIP。第三方大体积预训练权重未放入增量包。
